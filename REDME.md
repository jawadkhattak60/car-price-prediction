# Car Price Prediction Model
A Machine Learning projects using GradientBoostingRegressor model
## Project Overview
In this project user enter data and get the estimated price of car
## Tool Used
. Python
. Matplotlib
. Scikit-learn
. Joblib
. Streamlit
## Project Files
. app.py — Streamlit application
. Car_price_prediction_model.pkl — Trained ML pipeline
. requirements.txt — Required Python packages
## Installing Dependencies
. pip install -r requirements.txt
## Run The Application
. streamlit run app.py
